The app works without a connection, and <b>WorkManager</b> synchronizes local data with the remote server in the background.</p> <p><i>Created as a pet project during the Android mentoring course at School++.</i></p> <!-- Add screenshots or a short demo GIF here: --> <!-- <p align="center"><img src="docs/screenshots.png" width="800"></p> --> <h2>✨ Features</h2> <ul> <li>🔐 <b>Authentication:</b> sign up, sign in and auto sign-in</li> <li>👤 <b>Profile:</b> create and edit your own profile</li> <li>🔎 <b>Users:</b> search among all users and view their details</li> <li>📒 <b>Contacts:</b> add users to contacts, view details, search, delete a contact, delete several at once (multi-select) or by swipe</li> <li>🔔 <b>Push notifications</b></li> <li>📴 <b>Offline-first:</b> data stays available without a network and is synced later by WorkManager</li> </ul> <h2>🛠 Tech Stack</h2> <table> <tr><th align="left">Area</th><th align="left">Technologies</th></tr> <li><b>Presentation:</b> Fragments render a single UI state and send user intents to the ViewModel</li> <li><b>Domain:</b> use cases and repository interfaces, independent from Android and data sources</li> <li><b>Data:</b> repository implementations that combine the remote API (Retrofit) and the local database (Room)</li> </ul> <details> <summary><b>Offline-first synchronization</b></summary> <br> <ol> <li>The UI always reads data from the local Room database.</li> <li>User changes are saved locally first.</li> <li>WorkManager runs the synchronization between the local database and the remote server.</li> </ol> </details> <h2>🚀 Getting Started</h2> <p><b>Requirements:</b> Android Studio (latest stable), JDK 17+, Android device or emulator.</p>
