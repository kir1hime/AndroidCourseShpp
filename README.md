<div align="center"> <h1>📇 Profile Hub</h1> <p><b>An offline-first Android app for finding users and managing contacts</b></p> </div> <hr> <h2>📖 About</h2> <p>Users create accounts, configure their profiles, find other users, view their details and add them to contacts.</p> <p>The local database is the source of truth. The app works without a connection, and <b>WorkManager</b> synchronizes local data with the remote server in the background.</p> <p><i>Created as a pet project during the Android mentoring course at School++.</i></p>  <h2>✨ Features</h2> <ul> <li>🔐 <b>Authentication:</b> sign up, sign in and auto sign-in</li> <li>👤 <b>Profile:</b> create and edit your own profile</li> <li>🔎 <b>Users:</b> search among all users and view their details</li> <li>📒 <b>Contacts:</b> add users to contacts, view details, search, delete a contact, delete several at once (multi-select) or by swipe</li> <li>🔔 <b>Push notifications</b></li> <li>📴 <b>Offline-first:</b> data stays available without a network and is synced later by WorkManager</li> </ul> <h2>🛠 Tech Stack</h2> <table> <tr><th align="left">Area</th><th align="left">Technologies</th></tr> <tr><td><b>Language</b></td><td>Kotlin</td></tr> <tr><td><b>UI</b></td><td>XML Views, Fragments, RecyclerView, Glide</td></tr> <tr><td><b>Navigation</b></td><td>Jetpack Navigation</td></tr> <tr><td><b>Architecture</b></td><td>MVI, Clean Architecture, SOLID</td></tr> <tr><td><b>Dependency Injection</b></td><td>Hilt</td></tr> <tr><td><b>Networking</b></td><td>Retrofit</td></tr> <tr><td><b>Storage</b></td><td>Room, DataStore</td></tr> <tr><td><b>Async</b></td><td>Coroutines, Flow</td></tr> <tr><td><b>Background work</b></td><td>WorkManager, Push Notifications</td></tr> <tr><td><b>Tools</b></td><td>Git, Figma</td></tr> </table> <h2> <h2>🚀 Getting Started</h2> <pre><code>git clone https://github.com/kir1hime/AndroidCourseShpp.git</code></pre> <ol> <li>Open the project in Android Studio.</li> <li>Wait for the Gradle sync to finish.</li> <li>Select a device or emulator and press <b>Run</b>.</li> </ol> <h2>📂 Project Structure</h2> <pre><code>app/
